# Security

## Reporting a vulnerability

Please don't report security issues in public issues, discussions or Telegram.

Report them privately instead: open the app's repository on GitHub, go to the **Security** tab and click **Report a vulnerability**. Only the Theoron team can see the report.

Please include the app and its version, your macOS version, what the issue is and the steps to reproduce it. You can write in English, Russian or Ukrainian.

We'll reply as soon as we can, keep you posted while we work on a fix and credit you in the release notes if you'd like.

## Supported versions

Fixes go into the latest release of each app. Please check that the issue still happens in the latest version before you report it.
